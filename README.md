## Contexto

- O projeto consiste em um aplicativo de cadastro de livros com três telas e um banco de dados SQLite:
    - HOME
        - Deverá conter:
            - Uma imagem;
            - Um botão para a próxima tela.
    - LISTA DE LIVROS
            - Deve exibir a lista de livros cadastrados;
            - Deve ter um botão para cadasrar um novo livro.
    - CADASTRO DE LIVRO
        - Formulário com no mínimo 6 inputs para os atributos do cadastro.
            - Capa;
            - Título;
            - Autor;
            - Editora;
            - Edição;
            - Endereço de fabricação;
            - Data de publicação;
            - ISBN;
            - Descrição.

> [!NOTE]
> Todas as telas devem ser navegáveis entre si.
